# 🎯 Number Guessing Game

A simple and interactive Number Guessing Game built using Java.

## 🎮 Features

- Generates a random number between 1 and 100.
- Gives hints: Too High or Too Low.
- Allows a maximum of 7 valid attempts.
- Rejects guesses outside the range of 1–100.
- Awards 10 points for a correct guess.
- Provides an option to play again.
- Displays the final score.

## 🛠️ Technologies Used

- Java
- Java Scanner
- Random class

## ▶️ How to Run

1. Install Java JDK.
2. Download or clone this repository.
3. Open the project folder in VS Code or a terminal.
4. Compile the program:

   `javac NumberGame.java`

5. Run the program:

   `java NumberGame`
